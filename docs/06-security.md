# ۰۶ — امنیت

NOVA از الگوی **y-by-default / fail-closed** پیروی میکند: هر خطا در لایه امنیتی منجر به رد درخواست میشود.

## ۱) فایروال (`app/security.py` — `before_request`)

| لایه | اقدام |
|---|---|
| بررسی مسیر | رد مسیرهای طولانی (>512) و الگوهای `%00`, `%0d`, `%0a`, `../` |
| API discipline | تمام `POST /api/*` باید `Content-Type: application/json` و حداکثر 64KB باشند |
| نرخ کلی | Flask-Limiter با storage حافظه |
| هدرها | CSP، `X-Frame-Options: DENY`، `X-Content-Type-Options: nosniff`، Referrer-Policy، Permissions-Policy |
| کلیکجکینگ | frame-ancestors 'none' |
| Rotate logs | رویدادهای امنیتی در `instance/security.log` |

## ۲) CSRF

- `Flask-WTF CSRFProtect` روی تمام درخواستهای تغییردهنده.
- تمام فرمها شامل `<input type="hid" name="csrf_token" value="{{ csrf_token() }}">`.

## ۳) احراز هویت و دسترسی

- Session-based؛ قبل از هر عملیات حساس بررسی `session["user_id"]`.
- **DM**: فقط طرفین مکالمه میتوانند پیامها را بخوانند/جستجو کنند.
- **Channel**: عضویت در `server_members` الزامی.
- **Admin actions**: بررسی نقش (`owner` / `admin` / `moderator`).
- **ویرایش/حذف**: فقط صاحب پیام.
- **فایل**: دانلود فقط توسط `uploader_id` یا `recipient_id` (دیگران `403`).

## ۴) اعتبارسنجی ورودی

- طول پیام ≤ ۲۰۰۰ کاراکتر.
- نام کاربری: `^[A-Za-z0-9_]{3,24}$`.
- جستجو: ۲ تا ۱۰۰ کاراکتر، و از `POSITION(LOWER(...))` بهجای `ILIKE %...%` استفاده میشود تا `%` و `_` ورودی نتوانند الگو را دستکاری کنند.
- نمایش نتایج جستجو با `escapeHtml` + DOM → جلوگیری از XSS.
- آپلود فایل: لیست سفید پسوند/MIME، سقف ۲۰MB، نام ذخیرهی تصادفی، الگوی نام قبل از خواندن (جلوگیری از path traversal).

## ۵) اسرار و تنظیمات

- SECRET_KEY و DATABASE_URL از متغیر محیطی خوانده میشوند (فایل `.env`).
- فایل `.env` در `.gitignore` و با مجوز `600`.
- پسوورد قدیمی هاردکدی حذف شد؛ در صورت نبود متغیر، پسوورد تصادفی ساخته میشود.
- ابزار `secret_guard.py`: اسکن اسرار + رمزگذاری PBKDF2(480k)+Fernet + pre-commit hook.
- اسکنر فایلهای gitignored مثل `.env` را نادیده میگیرد تا مانع کامیت نشود.
