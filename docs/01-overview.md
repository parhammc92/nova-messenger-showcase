# ۰۱ — معرفی وvision

## NOVA چیست؟

**NOVA Messenger** یک پیامرسان وب (web messenger) است که دو الگوی محبوب را در یک محصول ترکیب میکند:

- **Discord** → ارتباط گروهی مبتنی بر *سرور* (community): سرورها، کانالها، نقشها، invite code.
- **Telegram** → ارتباط شخصی: چت ۱:۱، تایپینگ زنده، ریپلای، ویرایش/حذف، ریاکشن، تیک خواندهشدن، استیکر.

هدف: یک تجربهی واحد که هم «اجتماع» و هم «خصوصی» را پوشش دهد.

## مدل ذهنی محصول

```
                       ┌──────────────────────┐
                       │   NOVA Messenger     │
                       └──────────┬───────────┘
                                  │
              ┌───────────────────┴────────────────────┐
              │                                        │
      🌍 COMMUNITY (Discord)                  💬 PERSONAL (Telegram)
              │                                        │
   Server → Channel → Message               Contact → DM → Message
   Role / Invite / Pin                      Typing / Read / Reaction / Sticker
```

## تفاوتها و نقاط قوت

| ویژگی | پیادهسازی در NOVA |
|---|---|
| زنده بودن | Socket.IO برای تمام رویدادها (پیام، تایپینگ، حضور، ریاکشن، ویرایش) |
| امنیت | CSRF + rate limiting + فایروال داخلی + بررسی عضویت/مالکیت |
| دیتابیس | PostgreSQL با ایندکسهای مناسب و migration تجمعی (additive) |
| استقرار | Render + قابلیت بستهبندی به `.deb` و `.exe` |
| حریم خصوصی | فایلها فقط بین فرستنده و گیرنده قابل دانلوداند |
